## 📌 Sobre el Proyecto

Este repositorio contiene el código fuente de mi **portafolio web personal**, diseñado para presentar mi trabajo como desarrollador web, mi catálogo de proyectos funcionales, mis habilidades técnicas y mi filosofía de desarrollo.

El sitio está construido siguiendo las mejores prácticas de desarrollo web moderno: diseño responsivo (*Mobile First*), interfaz limpia en modo oscuro, carga rápida de recursos y componentes interactivos sin dependencias pesadas.

---

## 🛠️ Stack Tecnológico

| Tecnología | Descripción / Uso |
| :--- | :--- |
| **HTML5** | Estructura semántica y accesible |
| **Tailwind CSS** | Estilos modernos, diseño adaptativo y utilidades UI |
| **JavaScript (ES6+)** | Lógica de la aplicación, filtrado dinámico y manejo del DOM |
| **Git & GitHub** | Control de versiones y alojamiento continuo |
